**Portofolio Khalil Dev V2** adalah website portofolio pribadi untuk menampilkan profil, keahlian, teknologi, project, proses kerja, dan kontak sebagai **Software Engineer - Full Stack Developer**.

Website ini dibuat dengan tampilan modern, dark theme, animasi halus, responsive design, dan dibangun menggunakan framework utama **Next.js**.

🚀 Menjalankan Project

Clone repository:

```bash
git clone https://github.com/khalilurrahmanmahdi12/portofolio_v2.git
```

Masuk ke folder project:

```bash
cd portofolio_v2
```

Install dependency:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Build production:

```bash
npm run build
```

Jalankan production preview:

```bash
npm run start
```

---

🌐 Deployment

Project ini dideploy menggunakan **Vercel**.

Live website:

```text
https://portofolio-khalil-dev-v2.vercel.app/
```

Konfigurasi Vercel yang disarankan:

```text
Framework Preset: Next.js
Build Command: npm run build
Output Directory: kosongkan
Install Command: npm install
```

> Catatan: Untuk project Next.js di Vercel, bagian Output Directory sebaiknya dikosongkan agar Vercel dapat mendeteksi output build secara otomatis.
